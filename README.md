# 🐍 貪食蛇（Snake）— Vibe Coding 作業

## 📖 專案說明

這是一個使用純 **HTML、CSS 與 JavaScript** 實作的貪食蛇小遊戲。

本專案透過 **Vibe Coding（AI 協作開發）** 的方式，完整呈現從概念討論、規格書撰寫、程式實作、除錯，到發布至 GitHub Pages 的開發流程。

## 🎮 遊戲玩法

1. **控制蛇的移動：** 使用鍵盤方向鍵（↑、↓、←、→）控制蛇的移動方向。
2. **吃掉食物：** 蛇吃到隨機出現的紅色食物後，身體會增長一格，得分增加 `1` 分。
3. **碰撞判定：** 若蛇頭撞到牆壁或自己的身體，遊戲即結束。
4. **遊戲結束：** 顯示「Game Over」，並提供「重新開始」按鈕。
5. **調整速度：** 透過介面上方的速度選單（慢／中／fast），即時調整遊戲速度。
6. **開始新遊戲：** 點擊「開始遊戲」或「重新開始」，即可開始新的一局。

## 🚀 本地測試方式

本專案為純前端網頁，不需要安裝額外的依賴套件或啟動伺服器。

1. 將此儲存庫（repository）克隆至本機，或下載 ZIP 壓縮檔。
2. 解壓縮檔案（若使用 ZIP）。
3. 找到專案中的 `index.html`。
4. 使用 Chrome、Firefox、Safari 等現代瀏覽器直接開啟 `index.html`。
5. 開始遊玩！

## 🛠️ 技術要點

### 1. HTML：遊戲介面結構

負責建立遊戲介面，包含：

- 分數顯示。
- 速度選單。
- 開始遊戲按鈕。
- 遊戲棋盤。

### 2. CSS：版面配置與視覺設計

- 使用 **CSS Grid** 建立 `20 × 20` 的遊戲棋盤。
- 自訂蛇身、蛇頭與食物的顏色。
- 設計遊戲介面的版面與視覺呈現。

### 3. JavaScript：遊戲邏輯

**主要資料結構**

| 變數 | 功能 |
|---|---|
| `snake` | 使用陣列記錄蛇身各節的位置。 |
| `food` | 使用座標物件記錄食物的位置。 |
| `direction` | 記錄蛇目前的移動方向。 |
| `score` | 記錄玩家目前的得分。 |
| `tickInterval` | 控制遊戲更新的時間間隔。 |

**核心功能**

- **遊戲迴圈：** 使用 `setInterval()` 定期更新遊戲狀態。
- **碰撞檢測：** 判斷蛇是否撞到牆壁或自己的身體。
- **鍵盤事件：** 使用方向鍵控制蛇的移動。
- **方向限制：** 防止蛇直接反轉 `180°`，避免蛇頭立即撞上自己的身體。
- **速度調整：** 透過速度選單即時改變遊戲更新頻率，調整遊戲難度。
